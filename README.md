# Curso HTML - Clínica

Este repositório reúne um projeto simples de site para uma clínica, desenvolvido como parte de um curso de **HTML**.  
A ideia é praticar a estruturação de páginas e aplicar conceitos básicos de marcação.

---

## Funcionalidades
- Página inicial com apresentação da clínica  
- Seção dedicada aos profissionais e suas especialidades  
- Página de contato com formulário e informações de agendamento  
- Mapa de localização para facilitar o acesso  

---

## Tecnologias utilizadas
- HTML5 para estruturação  
- CSS3 para estilização básica  
- Imagens ilustrativas para enriquecer o conteúdo  

---


## Objetivo
O projeto tem como objetivo **aprender e praticar HTML** de forma aplicada, criando um site funcional e organizado para uma clínica fictícia.
